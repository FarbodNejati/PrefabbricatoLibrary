A *Unity Editor Tool* to easily organizing your Prefabs for **Level Design**.

This tool uses **Asset Labels** to tag Prefabs, helping you find the right Prop, NPC, or Effect Prefabs in no time!

# Installation
Install the latest release by opening the package  manager and installing by git url and entering the following:

```
https://github.com/FarbodNejati/PrefabbricatoLibrary.git
```

### Requirements:
* Unity 2022.3 or newer (Up to date for Unity 6000+)

# Quick Start
Access the Library from `Toolbar > Tools > Prefabbricato Library`

Now select the path where you store your Prefabs, and start a scan.

You can override the color of Asset Labels by right clicking on them and clicking `Edit Tag`
