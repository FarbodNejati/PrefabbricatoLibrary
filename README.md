# Prefabbricato Library
A *Unity Editor Tool* for easily finding and organizing you Prefabs for **Level Design**.

This tool mainly uses Unity **Asset Labels** to tag Prefabs, something that *everybody overlooks* when managing their assets.
By utilizing these asset labels, finding the right prop or NPC to place in your levels becomes a breeze!

# Installation
Install the latest release by opening the package  manager and installing by git url and entering the following:

```
https://github.com/FarbodNejati/PrefabbricatoLibrary.git
```

# Quick Start
Access the Library from `Toolbar > Tools > Prefabbricato Library`

### Requirements:
* Unity 2022.3 or newer (Up to date for Unity 6000+)
* UIElements (built-in unity package)
